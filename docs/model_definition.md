Problem:
Predict the duration of major railway disruptions in the Netherlands.

Target variable:
duration_minutes (regression)

Input features:
- Hour of day
- Day of week
- Month
- Number of affected stations
- Cause group
- Number of affected lines

Training data:
2018–2025 (to avoid bias from reporting changes introduced in 2017)

Evaluation metric:
Mean Absolute Error (MAE)
